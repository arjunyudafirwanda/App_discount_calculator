
# Discount Calculator - Python Flask

Aplikasi Kalkulator Diskon berbasis Python dan Flask untuk menghitung total pembayaran setelah penerapan diskon.

## Tentang Proyek

Discount Calculator merupakan aplikasi web sederhana yang dikembangkan menggunakan Python Flask. Aplikasi ini membantu pengguna menghitung harga akhir barang berdasarkan harga satuan, persentase diskon, dan kuantitas barang.

## Fitur

- Input harga satuan barang.
- Input persentase diskon.
- Input kuantitas barang.
- Perhitungan subtotal otomatis.
- Perhitungan nominal diskon.
- Perhitungan total pembayaran.
- Validasi input pengguna.
- Format mata uang Rupiah.
- Responsive user interface.
- Animasi interaktif dan efek hover.
- Fitur menyalin total pembayaran.

## Teknologi

- Python 3.11
- Flask 3.1
- HTML5
- CSS3
- JavaScript

## Instalasi dan Menjalankan Aplikasi

### 1. Clone repository

```bash
git clone URL_REPOSITORY
```

### 2. Masuk ke direktori proyek

```bash
cd App_discount_calculator
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Jalankan aplikasi

```bash
python app.py
```

### 5. Buka browser

```text
http://127.0.0.1:5000
```
